## 1. MỤC TIÊU & PHẠM VI KIỂM KÊ

Tài liệu này được lập nhằm đối chiếu toàn diện giữa **Tài liệu Yêu cầu Nghiệp vụ (SRS / Use Cases / Functional Requirements)** và **Hiện trạng Hệ thống Backend** thực tế trong mã nguồn Laravel 11. Các đối tượng kiểm kê bao gồm:
- **46 Yêu cầu Chức năng (Functional Requirements)** theo `docs/08_FUNCTIONAL_REQUIREMENTS.md`.
- **45 Trường hợp Sử dụng (Use Cases)** theo `docs/09_USE_CASES_FINAL.md`.
- **62 Phân mục API** theo `docs/12_API_SPECIFICATION.md`.
- **181 Endpoint REST API** thực tế đăng ký trong Laravel Route Collection (`php artisan route:list`).
- **72 File Database Migration** và **53 Eloquent Models** trong cơ sở dữ liệu PostgreSQL.
- **186 Bài kiểm thử tính năng (Feature Tests)** với 1.033 assertions đang chạy pass 100%.

## 3. TỔNG HỢP KHOẢNG TRỐNG (GAP ANALYSIS) & PHƯƠNG ÁN XỬ LÝ

### 3.1. Các chức năng có cơ sở dữ liệu nhưng THIẾU API (MISSING_API)
1. **Đại hội Thành viên & Biểu quyết Nghị quyết (`FR-COOP-004`):**
   - *Hiện trạng:* Đã có migration `000009_create_meetings_table.php` và `000010_create_votes_table.php` trong database. Chưa có Controller, Service, Request và API Route.
   - *Hành động:* Xây dựng `MeetingController`, `MeetingService`, DTOs, Requests và đăng ký nhóm route `/api/v1/meetings`.

2. **Quản lý Góp vốn bằng Quyền sử dụng Đất (`FR-COOP-002`):**
   - *Hiện trạng:* Đã có migration `000064_create_land_contributions_table.php` và Model `LandContributionModel.php`. Chưa có Controller và Route CRUD.
   - *Hành động:* Xây dựng `LandContributionController` trực thuộc phân hệ `Cooperative` với các endpoint `GET/POST/PUT/DELETE /api/v1/members/{id}/land-contributions`.

3. **Truy vấn Danh sách Thửa đất theo Xã viên (`FR-COOP-005`):**
   - *Hiện trạng:* Hệ thống chỉ mới có endpoint lấy thửa đất lồng theo vùng sản xuất (`GET /production-units/{unitId}/plots`). Khi xem chi tiết Xã viên ở tab 'Đất canh tác', frontend chưa có API `GET /api/v1/members/{memberId}/plots`.
   - *Hành động:* Bổ sung endpoint `GET /api/v1/members/{id}/plots` vào `MemberController`.

4. **Danh sách phẳng Thửa đất toàn HTX (`FR-AGRI-003`):**
   - *Hiện trạng:* Để chọn thửa đất khi ghi nhật ký canh tác hoặc gắn với xã viên, frontend cần API lấy toàn bộ thửa đất của HTX dạng phẳng kèm phân trang và lọc.
   - *Hành động:* Bổ sung endpoint `GET /api/v1/farm-plots` trong `PlotController`.

5. **Xóa Nhật ký Canh tác (`FR-AGRI-004`):**
   - *Hiện trạng:* `FarmingLogController` chỉ có các hàm `index`, `store`, `show`, `update`. Chưa có hàm `destroy` (`DELETE /api/v1/farming-logs/{id}`).
   - *Hành động:* Bổ sung hàm `destroy` với kiểm tra điều kiện (chỉ cho phép xóa khi lô chưa thu hoạch).

6. **Quản lý Danh mục Kho vật tư đa điểm (`FR-INV-004`):**
   - *Hiện trạng:* Đã có bảng `warehouses` (migration `000026`). Tuy nhiên backend hiện tại chỉ có API phiếu nhập/xuất kho và thẻ kho, chưa có API CRUD quản lý danh sách kho lưu trữ vật tư.
   - *Hành động:* Bổ sung `WarehouseController` với các endpoint `/api/v1/warehouses`.

7. **Báo cáo Công nợ Tổng hợp Đa chiều (`FR-FIN-005`):**
   - *Hiện trạng:* Backend có bảng công nợ và lịch sử thanh toán theo từng đối tượng, nhưng chưa có endpoint tổng hợp báo cáo công nợ toàn HTX (tổng nợ phải thu của xã viên, tổng nợ phải trả NCC, phân loại tuổi nợ).
   - *Hành động:* Thêm endpoint `GET /api/v1/reports/debt-summary`.

8. **Xuất Báo cáo Excel từ Phía Server (`FR-REP-003`):**
   - *Hiện trạng:* Đã hỗ trợ xuất PDF (Sổ cái, Sổ quỹ, Phiếu kho). Báo cáo Excel hiện nay đang phụ thuộc vào thư viện xuất phía Client (XLSX). Cần chuẩn hóa các endpoint xuất file Excel (`.xlsx`) từ server qua Laravel Excel.
   - *Hành động:* Bổ sung các endpoint `/api/v1/reports/export-excel/{type}`.

9. **Truy vết Vòng đời Xã viên trong Audit Log (`FR-AUD-002`):**
   - *Hiện trạng:* Đã có API truy vết chuỗi OCOP (`GET /api/v1/audit-logs/trace/ocop/{id}`). Chưa có endpoint tương tự cho Xã viên (`GET /api/v1/audit-logs/trace/member/{id}`).
   - *Hành động:* Bổ sung endpoint `GET /api/v1/audit-logs/trace/member/{id}`.

### 3.2. Chức năng THIẾU MODEL VÀ MIGRATION (MISSING_DATA_MODEL)
1. **Quỹ Tín dụng Nội bộ / Cho vay Nội bộ (`FR-FIN-004`):**
   - *Hiện trạng:* Theo Luật Hợp tác xã 2023, HTX có thể triển khai hoạt động tín dụng nội bộ cho thành viên vay phục vụ sản xuất. Trong hệ thống hiện tại hoàn toàn chưa có bảng cơ sở dữ liệu (`internal_loans`, `loan_schedules`), Model, Service và API.
   - *Khuyến nghị:* Phân hệ này là tính năng nâng cao (Giai đoạn 3), không ảnh hưởng đến luồng vận hành cốt lõi (Xã viên -> Canh tác -> Thu hoạch -> Kho -> OCOP). Có thể đưa vào backlog triển khai sau.

### 3.3. Các API cần chuẩn hóa Response & Validation (PARTIAL / UNVERIFIED)

   - *Hành động:* Refactor nhẹ `NotificationController` để đảm bảo định dạng JSON đồng nhất trên toàn hệ thống.
